Pax is a developer tool for building native apps & web pages.

User interface engine with a highly declarative user interface language Attaches to codebase (currently Rust; JavaScript/TypeScript and other languages coming soon.)

And attaches to visual design tool Declarative language can be read & written by a visual design tool And collaborated on with a visual copilot and multiplayer teammates [coming soon, Pax Pro: get early access]

Open Source

Both the cross-platform rendering runtimes and the vector design tool
that reads & writes .pax files are 100% free, MIT licensed.

Mission statement: Building software should be as intuitive as Minecraft, and as creatively expressive as painting.
By empowering more creators with higher fidelity creative tools, we aim to improve the (digital) human condition.

Pax Pro

We're developing a team collaboration portal that seeks to bring
human imagination closer to the metal.

Pax Pro is a place to collaborate with AI and teammates,
using visual and AI chat tools to perform surgery on a codebase.
Non-developers can fetch the latest from GitHub and publish their work as pull requests.
