Pax on GitHub

Build anything in 2D

Make apps, websites, games, visualizations, and more – Pax is an open-ended and extensible toolkit for building interfaces on screens.

Features include 2D vector drawing on the GPU¹, animations, text, interactions, responsive layouts, gradients, form controls, an extensible component system, screen reader support, scrolling, clipping/occlusion, and raster image rendering.

¹ GPU rendering is available under a feature flag and CPU rendering is the default fallback until GPU rendering is production-ready. See the roadmap.

Ship to any device²

Pax is written in Rust and runs on metal, interfacing as directly as practical with the target's CPU, GPU, and memory.

This enables Pax to be highly portable and performant, achieving up to 240FPS rendering, runnable natively on practically any computer or mobile device.

Pax's primary design challenge is to offer high-level ergonomics, inspired by HTML & CSS among others, while prioritizing portability, performance, and resource efficiency.

² Pax is designed to target any native desktop or mobile operating system, and could be extended to embedded devices. However, during beta Pax targets only the web browser via WebAssembly, with feature-incomplete alpha support for native macOS and iOS.

Free & open source

Pax on GitHub

Pax started as a sabbatical project by Zack Brown, then became incubated through a company along with Warfa Jibril and Samuel Selleck, backed by South Park Commons and some other cool people.

Pax's long-term mission is two-fold: (1) to empower art on screens and (2) to enable more of humanity to create software.

Pax is licensed MIT or Apache 2.0, at your choice.
