Make apps, interactive websites, games, visualizations, and more – Pax is an open-ended and extensible toolkit for building interfaces on screens.

Ship to any device

Pax is written in Rust and compiles to run on the metal, interfacing as directly as practical with the target's CPU, GPU, and memory.

This enables Pax to be highly portable and performant, achieving up to 240FPS rendering, runnable natively on practically any computer or mobile device.

Pax's primary design challenge is to offer high-level ergonomics, inspired by HTML & CSS among others, while prioritizing portability, performance, and resource efficiency.

Current status

Pax is currently in beta. We aim for the project to become "a better choice than HTML" for many kinds of apps & websites. The design & execution burden to achieve this goal is high, but we believe it a worthwhile challenge to improve humanity's interface with machines.
