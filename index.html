In pursuit of a better interface
between humans and machines

Pax is a user interface engine
and design tool
that work together.

100% open source. Built in Rust. 🦀

Visual Control

Pax Designer reads & writes user interface definitions as code, while offering the creative control of a professional design tool

An AI Canvas

Pax uniquely enables AI collaboration on a visual canvas, just like a codebase copilot.

Native, fast, the future

Pax projects build into pure native apps or lightning fast web apps with GPU rendering, thanks to modern technologies: WASM, WebGPU / WebGL, and Rust.

Multiplayer, coming soon

Pax today is a public open source preview.
